*mentor.txt*  Learning-oriented AI assistance for Neovim.

==============================================================================
INTRODUCTION                                                      *mentor.nvim*

Mentor.nvim balances observation, coaching, and explicitly requested
implementation. It is autonomous in understanding a project and deliberately
restrained in modifying it. This build is the Milestone 1 shell: Coach chat
with a fake offline provider, project identity, and local storage. Observer
and Implement arrive in later milestones.

Setup: >lua

    require("mentor").setup({
      providers = {
        default = {
          endpoint = "https://api.example.com/v1",
          model = "tool-calling-model",
          api_key_env = "MENTOR_API_KEY",
        },
      },
    })
<

Run `:checkhealth mentor` for actionable dependency and configuration reports.

==============================================================================
COMMANDS                                                        *mentor-commands*

:MentorChat                 Open the Coach conversation window for the
                            current project. In the buffer, edit a line
                            starting with "> " and press <CR> to send it.

:MentorChatAsk {question}   Ask Coach immediately.

:MentorStop                 Cancel running operations. Late results from a
                            cancelled operation are never applied.

:MentorStatus               Show configuration, providers, project, storage,
                            and active operations.

==============================================================================
CONFIGURATION                                                *mentor-config*

See README.md for the current reference. Shipped defaults for limits,
notification cadence, and observation timing are validated at setup(); invalid
values produce named, actionable errors.

Local data lives in stdpath("data")/mentor; credentials are read from the
environment at request time and are never stored.
